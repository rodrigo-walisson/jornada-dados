## Rotina da semana

1. **Sessão 1 (1h30):** ler o capítulo e digitar os exemplos do livro no notebook. Digite, não copie e cole: os dedos aprendem junto.
2. **Sessão 2 (1h30):** fazer os exercícios do notebook. Cada um tem uma célula de verificação que mostra ✅ ou ❌.
3. **Sessão 3 (2h):** exercícios de fim de capítulo do livro + resumo em `notas/aprendizados.md` + commit.

## Como abrir os notebooks

1. Abra a pasta `Jornada cientista de dados` no VS Code.
2. Clique no arquivo `.ipynb`.
3. No canto superior direito, em **Select Kernel**, escolha **Python Environments → .venv**.
4. Execute cada célula com `Shift + Enter`.
